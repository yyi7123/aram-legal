# 海斗助手 · 法律页面

用于 GitHub Pages 的静态隐私政策 / 服务条款。无需构建、无需服务器。

## 上传步骤

1. 在 GitHub 新建 **Public** 仓库，例如 `aram-legal`
2. 把本目录的 `index.html`、`privacy.html`、`terms.html` 上传到仓库根目录
3. 仓库 **Settings → Pages**
4. **Build and deployment → Source** 选 **Deploy from a branch**
5. Branch 选 `main`，Folder 选 `/ (root)`，点 **Save**
6. 等 1–2 分钟，访问：
   - `https://<你的用户名>.github.io/aram-legal/`
   - `https://<你的用户名>.github.io/aram-legal/privacy.html`
   - `https://<你的用户名>.github.io/aram-legal/terms.html`

## 注意

- 这是模板，不构成法律意见；正式发布前建议请专业人士按你的运营地区复核。
- GitHub Pages 在国内访问可能不稳定；如果主要用户在国内，可改用 Cloudflare Pages（`*.pages.dev`）或 Netlify，文件相同。
- 商店/QA 提交时填 `https://...github.io/...` 的页面地址，不要填 `github.com/.../blob/...` 的文件页。
